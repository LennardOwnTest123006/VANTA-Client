Release of VANTA Client for Minecraft Java Edition 1.21.11 (Fabric Loader 0.19.5, Fabric API 0.141.6+1.21.11, Java 21; all unchanged). It adds **Vanta Nexus**: one screen with an assistant that changes your own client when you ask, a HUD Designer with named layouts and presets, the profiles, live performance values, waypoints with screen markers, Vanta Lab and its own settings. The assistant runs on a **strictly local AI**: `llama-server` from llama.cpp and the Qwen3-1.7B model on your PC, downloaded once and only after you agree, verified by SHA-256, offline afterwards. No cloud AI, no API key, no account, no telemetry. The client contacts Modrinth (Mods & Shaders) and, only when you install the Local AI, github.com (the runtime) and huggingface.co (the model), which redirect the two downloads to their own file hosts (GitHub's objects.githubusercontent.com, Hugging Face's CDN hosts). Nothing else, ever. The assistant's prompts go to 127.0.0.1 only.

## Added

- **Vanta Nexus** (default key N, the *Vanta Nexus* button on the main menu after Multiplayer, "Open Vanta Nexus" in the command palette, `/vanta nexus`): a screen with seven sections. *AI Assistant* with a status pill (Ready, Starting, Busy, Not installed, Not available on this system), the transcript with your messages and the assistant's answers, "Applied: ..." and "Not applied: ..." receipts, an Undo button for the last applied change, example prompts ("Make my HUD minimal", "Only show FPS and coordinates", "Create a recording profile", "Move the FPS counter to the bottom right"), Enter sends. *HUD Designer*, *Profiles*, *Performance*, *Waypoints*, *Vanta Lab* and *Settings* (below). Every button stays reachable in a small window
- **What the assistant can do**, each action validated against what really exists before it runs: show, hide, move, scale and set the opacity of HUD widgets, show exactly a set of widgets, save and load named HUD layouts, apply a HUD preset; switch to a profile or create one from the current state; apply a performance preset or run Smart Boost; change a setting of the Video, HUD, Performance or Accessibility categories; add a waypoint at your position, remove, enable or disable one; switch a Vanta Lab feature. It never touches keybinds, other players, the game world or the network. Rejected actions are listed with the reason (unknown widget, setting not allowed, value out of range, ...). **Undo** takes back the last assistant change; the last 20 turns are kept
- **Local AI** (`llama-server` from llama.cpp release b11429, MIT, with the Qwen3-1.7B Q8_0 GGUF model, Apache-2.0). Nothing downloads before you click **Install Local AI**: the install card in Nexus names the runtime, the model, the download size for your system, the folder, the hosts and the licences first. The setup screen shows the steps (Checking Local AI, Downloading Local AI runtime, Downloading Local AI model, Verifying files, Installing, Initializing Local AI, Vanta Nexus ready) with progress, bytes and speed, Cancel, and Retry with the reason after a failure. Every file is checked against the size and SHA-256 of the Local AI manifest the client ships; a mismatch deletes the file. The download is the runtime archive for your system, 11.5 MB (macOS Intel) to 19.4 MB (Windows x64), plus the model, 1.83 GB (1,834,426,016 bytes); installed it needs about 2200 MB of disk space and 3072 MB of RAM while the assistant runs (values from the manifest)
- **Where the Local AI lives.** With the VANTA Launcher 1.4.0 the launcher installs it into its own folder and writes the note `config/vanta/local-ai.json` into the game folder; the client then uses that install read-only (Nexus says "installed by the VANTA Launcher" and hides Install and Remove). Without the launcher, or when the note points at a folder without a complete install (for example after *Not now* in the launcher's offer), the client installs into `config/vanta/local-ai/`. Inside: `installed.json`, `runtime/<tag>/<platform>/`, `models/<file>`, `downloads/` while downloading, `logs/llama-server.log`. Nexus → Settings has **Verify files** (full re-hash), **Reinstall** and **Remove Local AI** (asks first; deletes only this folder); a quick check (size and modification time) runs at every start
- **How the Local AI runs.** The client starts `llama-server` on 127.0.0.1 on a free port with a 4096-token context on the CPU (no GPU offload) and the prompt is answered through the local HTTP API; log in `logs/llama-server.log`. The server stops after 10 minutes without a question (*Settings → Vanta Nexus → Stop the Local AI after idle minutes*, 1 to 120) and starts again on demand; *Keep the Local AI running* leaves it in RAM while the game runs; *Local AI CPU threads* 0 picks at least 2, at most 8, two fewer than your cores. On game exit the process is stopped. Supported systems: Windows, Linux and macOS on x64 and ARM64 (including Apple Silicon); every other system gets an honest "Local AI is not available on this system" state and the rest of Nexus works as before
- **HUD Designer**: the built-in and saved HUD layouts with Load, Duplicate and Delete (your own layouts), Save current under a name (blank, too long or taken names are refused), New layout from a preset, the six Nexus HUD presets as buttons (each one undoable change that keeps your widget positions; the crosshair always stays) and Open editor for the HUD editor, which remains the place to move, resize, scale and set the opacity of every widget. The presets: **Minimal** (FPS and coordinates), **PvP** (FPS, ping, CPS, keystrokes, armor, durability, effects), **Recording** (FPS, clock, coordinates, direction, keystrokes, version at 90 %; no server address), **Survival** (FPS, coordinates, direction, biome, clock, armor, durability, effects), **Building** (coordinates, direction, biome, clock at 90 %) and **Full** (every widget)
- **Profiles section** in Nexus with the profile cards and actions of the Profiles screen, and two new built-in profiles: **Survival** (Survival HUD, Balanced preset, FOV 75, HUD text shadow, default crosshair) and **Minimal** (FPS and coordinates, Balanced preset, HUD opacity 90 %, Thin crosshair, no menu particles, 2.5 s notifications). Seven built-ins now: Default, PvP, Survival, Building, Recording, Performance, Minimal
- **Performance section** with live values only, refreshed every tick: FPS now, frame time p50 and p99 of the last window, hitches over 50 ms, ping (Singleplayer when there is no server), render distance, GPU, Java memory used, committed and maximum, the Smart Boost status, the preset buttons, Boost FPS and Open Performance Center. "n/a" wherever a value is missing; nothing is estimated
- **Waypoints**: saved places per world (singleplayer worlds by their folder name, servers by their address), each with a name of up to 48 characters, a category (Home, Base, Farm, Portal, Resource, Other or your own) and one of eight colours, stored in `config/vanta/waypoints.json` (up to 500). The Nexus Waypoints section lists the current world's waypoints with distance and an enable toggle, searches, sorts by name, distance or newest, has an All worlds view, an add and edit dialog with the coordinates prefilled from your position, and delete with confirmation. **Screen markers** (a diamond in the waypoint colour with name and distance) are drawn for the enabled waypoints of the current world within the marker distance, nearest on top; nothing with F1, the F3 overlay, a HUD-free screenshot or a VANTA screen open. *Settings → Waypoints*: Waypoint markers (on), Marker distance (512 blocks, 16 to 4096), Show distance on markers (on), Marker size (1.0, 0.5 to 2.0)
- **Vanta Lab**: five optional features, all off by default, each a toggle in Nexus → Vanta Lab and *Settings → Vanta Lab*. **Dynamic HUD**: the HUD fades out after 10 seconds without input while you are in a world and comes back on any input (it never fades while a screen is open). **Animated crosshair**: the crosshair spreads while you move and when you attack. **Waypoint beams**: a light beam in the world at every enabled waypoint within the marker distance; the screen markers work without it. **Frame time HUD graph**: a HUD element that draws the last 120 frame times as a sparkline with p50 and p99 labels and frames over 50 ms highlighted; the widget is listed in the HUD editor only while the feature is on, and the Nexus presets never add it. **Screen transitions**: VANTA screens fade and slide when they open and close; off under reduced motion, never blocking input
- **Settings → Vanta Nexus**: *Vanta Nexus assistant* (on), *Offer the Local AI install when Nexus opens* (on; the install itself always asks), *Stop the Local AI after idle minutes* (10), *Local AI CPU threads* (0 = automatic), *Keep the Local AI running* (off), *Show the model's reasoning* (off; the model is asked without a thinking phase, so this stays empty). The Nexus Settings section has the same rows, the Local AI status card and a link to the full Settings screen
- **First start**: once per client version, the main menu shows "Vanta Nexus: Local AI is not installed. Open Nexus to install it" with *Open Nexus* and *Not now* while the Local AI is not installed and not managed by the launcher. Nothing downloads from it; the choice is remembered in `config/vanta/nexus-first-start.json`
- The conversation with the assistant is kept in `config/vanta/nexus-chat.json` (the last 50 turns) and restored at the next start; *Clear chat* empties it

## Improved

- Built-in profiles: the HUD layouts of PvP, Building and Recording are now the Nexus HUD presets applied to the Default layout, so a profile and the assistant's "Make my HUD ..." produce the same HUD. Built-in profiles you never changed are refreshed once on the first start of 1.4.0; renamed or edited built-ins and your own profiles keep their content. Survival and Minimal are added once to existing installs and are not re-added if you delete them
- Settings: the new categories Vanta Nexus, Waypoints and Vanta Lab in the settings rail (it scrolls when the window is short); the command palette finds "Open Vanta Nexus" also under nexus, ai, assistant, local ai, hud designer, waypoints and lab
- The HUD editor lists the frame time graph only while its Vanta Lab feature is on; a layout that contains it keeps it, hidden, while the feature is off
- Nothing that the assistant or the Local AI do runs on the render thread: downloads, the server process and its answers run on a background thread and are handed back to the game thread, like the Modrinth browser

## Notes

- **Privacy.** The client contacts Modrinth (Mods & Shaders) and, only when you install the Local AI, github.com (the llama.cpp runtime archive) and huggingface.co (the model); each answers with a redirect to its own file host, which the client follows (GitHub's release asset host objects.githubusercontent.com, Hugging Face's CDN hosts). Nothing else, ever. The assistant never sends anything anywhere: prompts go to 127.0.0.1 only; no cloud AI, no API key, no account, no telemetry
- **The Local AI is optional.** Without it, the HUD Designer, Profiles, Performance, Waypoints, Vanta Lab and Settings sections of Nexus work in full; only the assistant needs it. A small model answering on your CPU can misread a request; every action is validated, rejections are explained, and Undo is one click away
- **Which files, from where.** Runtime archive from `https://github.com/ggml-org/llama.cpp/releases/tag/b11429` (one of six: Windows x64 19.4 MB, Windows ARM64 12.2 MB, Linux x64 17.7 MB, Linux ARM64 13.7 MB, macOS Apple Silicon 12.0 MB, macOS Intel 11.5 MB), model `Qwen3-1.7B-Q8_0.gguf` from `https://huggingface.co/Qwen/Qwen3-1.7B-GGUF` (1.83 GB). Sizes and SHA-256 digests are in `shared/local-ai/local-ai.json` of the repository, embedded in the client as `assets/vanta/local-ai.json` and printed into `LOCAL-AI.txt` of the full release zip. Licences: llama.cpp MIT, Qwen3-1.7B Apache-2.0
- With the VANTA Launcher, install the Local AI there (it asks at its first start; *Settings → Local AI*): the game then uses the launcher's install and does not download its own copy. A client installed by hand installs into `config/vanta/local-ai/`
- Minecraft 1.21.11, Fabric Loader 0.19.5, Fabric API 0.141.6+1.21.11 and Java 21 are unchanged. The mods bundle `vanta-client-1.4.0-mods.zip` carries the VANTA jar, Fabric API and the Performance pack mods that may be redistributed, as before; the Local AI is never inside a release file
- VANTA is a legitimate client: no cheats, no combat automation, no packet manipulation, no anti-cheat bypasses and no player tracking. Waypoints show only places you saved yourself; the assistant only changes your own client
- Every file is published by the release workflow with its SHA-256 in the release manifest and in `SHA256SUMS.txt`; compare it before installing. Nothing is code-signed
