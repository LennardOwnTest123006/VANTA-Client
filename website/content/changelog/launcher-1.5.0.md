VANTA Launcher 1.5.0 is released together with VANTA Client 1.5.0 so both keep the same version number. The launcher installs and offers VANTA Client 1.5.0; installing, PLAY, the Local AI, the Logs page and the updater work as in 1.4.1.

## Notes

- The frame-rate fix of client 1.5.0 is in the client itself: the launcher never writes Minecraft's video options, and the client turns the default VSync off once on its first start
- Launchers from 1.0.1 on see the update by themselves and offer the file that matches how they were installed; on Windows that is `VANTA-Launcher-1.5.0.msi`
