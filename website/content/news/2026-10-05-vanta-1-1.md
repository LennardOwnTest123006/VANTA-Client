VANTA Client 1.1.0 and VANTA Launcher 1.1.0 are out, both for **Minecraft Java Edition 1.21.11** with Fabric Loader
0.19.5, Fabric API 0.141.6+1.21.11 and Java 21, as before. They are published as the GitHub Releases
[`client-v1.1.0`](https://github.com/LennardOwnTest123006/VANTA-Client/releases/tag/client-v1.1.0) and
[`launcher-v1.1.0`](https://github.com/LennardOwnTest123006/VANTA-Client/releases/tag/launcher-v1.1.0); the
[Download page](https://vanta-client.netlify.app/download) lists every file with its size and SHA-256.

## Mods & Shaders

The VANTA main menu has a new **Mods & Shaders** button (it is also in Settings, the Performance Center and the
global search). It searches [Modrinth](https://modrinth.com) for Fabric mods, shader packs for Iris and resource packs
that have a version for Minecraft 1.21.11, and installs them with the projects they require. Every file comes from the
address Modrinth publishes and is checked against the SHA-512 Modrinth publishes for it; a file that does not match
is deleted. Mods that VANTA installed can be switched off, on or removed, and files you added yourself are listed but
never touched. Fabric loads mods only at start, so after a change a banner offers to restart: when the VANTA Launcher
started the game, *Restart game* brings you straight back.

The VANTA Launcher has the same on its new **Mods** page, for the VANTA game folder that the Minecraft Launcher
profile *VANTA 1.21.11* uses too.

## The Performance pack

The Performance Center's presets only change vanilla video options. For more, VANTA 1.1.0 can install the
**Performance pack**: [Sodium](https://modrinth.com/mod/sodium), [Lithium](https://modrinth.com/mod/lithium),
[FerriteCore](https://modrinth.com/mod/ferrite-core), [ImmediatelyFast](https://modrinth.com/mod/immediatelyfast),
[EntityCulling](https://modrinth.com/mod/entityculling) and [Iris Shaders](https://modrinth.com/mod/iris). In the game
it is one click on the Mods & Shaders screen; the VANTA Launcher installs it by default and has a setting to turn it
off. No version is fixed in VANTA: the newest Fabric build of each mod for 1.21.11 is looked up on Modrinth when it is
installed.

These mods are independent projects by their own authors, under their own licences. VANTA does not ship them in its
files; it downloads them from Modrinth for you. We do not promise an FPS number: how much faster the game runs depends
on your computer. With Iris installed, the Shaders tab installs shader packs, and *Open shader settings* takes you to
the Iris screen to pick one. [Mods & Shaders](https://vanta-client.netlify.app/documentation/mods-and-shaders) in the
documentation explains all of it, including how to choose a shader pack.

## PLAY via Minecraft Launcher

Signing in with Microsoft inside the VANTA Launcher still needs an application id approved by Mojang, which the
project does not have. Until it does, the launcher's main button is now **PLAY via Minecraft Launcher**: one click sets
up or updates the profile *VANTA 1.21.11* in the official Minecraft Launcher and opens it, and the Minecraft Launcher
signs you in.

Some of you saw the profile appear only after restarting the PC. The reason: the Minecraft Launcher reads its
profiles only when it starts, and it often keeps running in the system tray after its window is closed. The VANTA
Launcher now checks for a running Minecraft Launcher before it writes the profile and asks you to close it completely
first. It never closes it for you. *Open Minecraft Launcher* starts it again afterwards.

## Fixed

- **Client**: with no worlds yet, *Singleplayer* opens *Create New World*, and leaving it with *Cancel* or Escape
  showed the vanilla title screen. Every way back to the title screen now ends on the VANTA main menu.
- **Launcher**: when the launcher could not start, it closed without a message. It now shows a dialog with the reason
  and writes `startup-error.txt` into the `logs` folder of its data directory
  (`%APPDATA%\VANTA Launcher\logs` on Windows). If the launcher does not start for you, please attach that file and
  `launcher-0.log` to your report.

## What CI checks now

- VANTA's headless game test runs a second time with the newest 1.21.11 versions of the six Performance pack mods
  loaded, and fails when one of them is missing or the game crashes.
- A live check downloads the pack through VANTA's own Modrinth code and verifies every SHA-512; the launcher's
  integration test installs it from Modrinth and checks each jar against Modrinth.
- A new job starts the launcher on a Windows runner from the `.msi`, the portable zip and the jar, and fails unless
  each of them opens the launcher window.

These checks cover the combinations they run; other mods and other Windows setups are not tested.

## Privacy

The client still collects nothing. The only service it contacts itself is Modrinth, and only while you use Mods &
Shaders: your search text, project and version ids, the SHA-512 checksums of mod files VANTA did not install (so it
can recognise them) and a User-Agent naming VANTA. No account data, player name or statistics. The details are on the
[Privacy page](https://vanta-client.netlify.app/privacy).

## Updating

The VANTA Launcher offers both updates itself; check the SHA-256 of anything you download by hand. Launcher 1.0.0
still offers the `.msi` on Windows and the `.tar.gz` on Linux even for portable and jar setups; if that is you,
choose *Not now* and download the portable zip or your jar from the
[`launcher-v1.1.0`](https://github.com/LennardOwnTest123006/VANTA-Client/releases/tag/launcher-v1.1.0) release. The
files are still not code-signed, so Windows SmartScreen may warn; Smart App Control on Windows 11 can block them
without a *Run anyway* option. The
[troubleshooting guide](https://vanta-client.netlify.app/documentation/troubleshooting) covers both.

As always: VANTA contains no cheats, no combat automation, no packet manipulation and no anti-cheat bypasses.
