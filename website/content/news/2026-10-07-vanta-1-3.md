VANTA Client 1.3.0 and VANTA Launcher 1.3.0 are out, both for **Minecraft Java Edition 1.21.11** with Fabric Loader
0.19.5, Fabric API 0.141.6+1.21.11 and Java 21, as before. The release workflow publishes them as the GitHub Releases
`client-v1.3.0` and `launcher-v1.3.0`; the [Download page](https://vanta-client.netlify.app/download) lists every file
with its size and SHA-256. This release answers three reports.

## "Singleplayer only offers Create New World"

VANTA runs in its own game folder, so Singleplayer only saw that folder's worlds, and a new VANTA player had none. In
1.3.0 Singleplayer uses the worlds of your normal Minecraft folder, like the vanilla game: the folder the VANTA
Launcher set the game up for, or `.minecraft`. Nothing is moved, copied or deleted. The new setting *Settings →
General → Singleplayer worlds* switches between *Minecraft folder* (the default) and *VANTA folder*; a change takes
effect at the next start. While the Minecraft folder has no world and the VANTA folder has one, the VANTA folder stays
in use, so worlds you already made with VANTA do not disappear. The details, including where earlier VANTA worlds
are, are in the
[troubleshooting guide](https://vanta-client.netlify.app/documentation/troubleshooting#singleplayer-opens-create-new-world-instead-of-my-worlds).

## "My graphics setting jumps back to Fancy"

Minecraft 1.21.11 switches its graphics preset to *Custom* as soon as you change one option that belongs to the
preset, such as render distance or clouds. VANTA could not show *Custom* and showed its default, *Fancy*. Now the
*Graphics* row shows *Custom*, and picking Fast, Fancy or Fabulous applies that preset again. Built-in profiles now
change only the options they are about, so activating *Default* no longer resets your volumes, mouse sensitivity or
GUI scale (a built-in profile you edited keeps its content).

With the Performance pack, *Video Settings* is Sodium's screen. On its own, Sodium throws away a change that was not
applied when you leave with Escape. With VANTA, Escape now keeps it, like *Apply* (Alt+A), as in vanilla Video
Settings.

## Short freezes

VANTA 1.3 removes two sources of them. Closing a VANTA screen rewrote every profile and the cosmetics file on the
render thread; now only what changed is written. And the *VANTA 1.21.11* profile in the Minecraft Launcher carried
only `-Xmx`, so the game ran on plain JVM defaults there. The launcher now writes the same memory and G1
garbage-collector arguments as its own PLAY, plus your extra JVM arguments when they fit one line. JVM arguments you
edited in the Minecraft Launcher are kept. Run *PLAY via Minecraft Launcher* once after updating so the profile gets
the new line.

## Smart Boost

Smart Boost is new in the Performance Center. It is a local, rule-based tuner: no model, no network, nothing leaves
your computer. Once after you install or update VANTA, it measures real gameplay (up to three presets, 25 s each)
and picks the preset your PC runs smoothly: Max FPS, Low, Balanced, High or Ultra. Pause menus, an unfocused window
and standing idle are not measured. It never changes Fast / Fancy / Fabulous, the frame-rate limit or VSync, and it
never overrides an option you changed yourself. The Smart Boost card shows the result, the options it leaves alone,
**Re-tune** and **Undo**. An optional switch, off by default, lets it adjust the render distance while you play.
How it decides is described in
[Performance Center → Smart Boost](https://vanta-client.netlify.app/documentation/performance#smart-boost).

## What was not measured

- FPS on real graphics cards. CI runs Smart Boost and a new hitch probe in the headless game test on a software
  renderer; that checks the rules and VANTA's own cost, not your PC. Smart Boost reports what it measured on yours,
  and we promise no number.
