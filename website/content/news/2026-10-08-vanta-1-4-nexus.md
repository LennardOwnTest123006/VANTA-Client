VANTA Client 1.4.0 and VANTA Launcher 1.4.0 are out, both for **Minecraft Java Edition 1.21.11** with Fabric Loader
0.19.5, Fabric API 0.141.6+1.21.11 and Java 21, as before. The release workflow publishes them as the GitHub Releases
`client-v1.4.0` and `launcher-v1.4.0`; the [Download page](https://vanta-client.netlify.app/download) lists every file
with its size and SHA-256 in three sections: Windows, cross-platform and the complete release.

## Vanta Nexus

Press N (or click *Vanta Nexus* on the main menu) and one screen opens with seven sections: the **AI Assistant**, the
**HUD Designer** with named layouts and six presets, your **Profiles**, **Performance** with live values only,
**Waypoints**, **Vanta Lab** and the Nexus **Settings**.

The assistant changes your own client when you ask, in plain English: "Only show FPS and coordinates", "Create a
recording profile", "Move the FPS counter to the bottom right". It can show, hide, move, scale and set the opacity of
HUD widgets, apply HUD presets and saved layouts, switch or create profiles, apply performance presets or run Smart
Boost, change settings of the Video, HUD, Performance and Accessibility categories, add, remove, enable or disable
waypoints, and switch Vanta Lab features. Every action is checked against what really exists before it runs; what was
not applied is listed with the reason, and **Undo** takes back the last change. It never acts in the game world and
never touches other players, keybinds or the network.

## The Local AI, strictly local

The assistant runs on a model on your own PC: `llama-server` from the llama.cpp release b11429 (MIT) with the
Qwen3-1.7B Q8_0 model (Apache-2.0). There is no cloud AI, no API key, no account and no remote fallback. The
model answers on your CPU, so it can misread a request; that is why every action is validated and Undo is one
click away.

Both files have to be downloaded once, and this is the only time the client contacts anything but Modrinth: the
runtime archive for your system comes from github.com (11.5 MB for macOS Intel to 19.4 MB for Windows x64) and the model
from huggingface.co (1.83 GB, 1,834,426,016 bytes). Every file is verified against the size and SHA-256 recorded in the
Local AI manifest the client and the launcher ship. After that the assistant works offline: the client starts
`llama-server` on 127.0.0.1 and your questions go there and nowhere else. The server stops itself after ten minutes
without a question and starts again when you ask something. It needs about 2200 MB of disk space and 3072 MB of RAM
while it runs, on Windows, Linux or macOS with an x64 or ARM64 processor; any other system gets an honest "not
available on this system" and the rest of Nexus works without it.

**Nothing downloads on its own.** With the VANTA Launcher 1.4.0, the first start asks once (*Install the Local AI?*,
with the files, sizes, hosts and licences); *Not now* keeps it off, and *Settings → Local AI* has Install, Verify files
and Remove at any time. Installed by the launcher, the Local AI lives in the launcher's own folder and the game uses it
from there. Without the launcher, Vanta Nexus shows the same facts on an install card and downloads only after you
click *Install Local AI*, into `config/vanta/local-ai`. Remove deletes only that folder. The details are in the
documentation: [Local AI](https://vanta-client.netlify.app/documentation/local-ai) and
[Vanta Nexus](https://vanta-client.netlify.app/documentation/nexus).

## Waypoints, HUD Designer, Vanta Lab

**Waypoints** are saved places per world (singleplayer worlds by their folder, servers by their address) with a name,
a category and a colour, drawn as markers with their distance on your screen for the enabled waypoints within 512 blocks
by default. They live in `config/vanta/waypoints.json`, are shared with nobody and show only places you saved
yourself. The **HUD Designer** keeps named layouts (save, load, duplicate, delete) and applies the same six presets the
assistant uses: Minimal, PvP, Recording, Survival, Building and Full. The built-in profiles PvP, Building and Recording
now carry those layouts, and two new ones, Survival and Minimal, join them. **Vanta Lab** holds five optional features,
all off by default: Dynamic HUD (fades out after 10 seconds without input), an animated crosshair, waypoint beams in the
world, a frame time graph HUD element (the last 120 frame times with p50 and p99) and screen transitions.

## VANTA Launcher 1.4.0

Besides the Local AI the launcher gets a status line on its Home page, the command-line flags `--install-local-ai`,
`--local-ai-status` and `--remove-local-ai`, and writes a small note into the game folder so the client finds the
launcher's install. From this release on the Windows installer is the `.msi` only; the `.exe` of earlier releases stays
on their release pages. The launcher jars for Windows, Linux and macOS and the Linux app are unchanged and listed under
*Cross-platform* on the Download page.

## What was not measured

- Answer quality and speed of the assistant on real PCs. CI runs the assistant end to end in the headless game test
  (one request, the HUD must end up as asked) on a software renderer; that proves the path, not how a 1.7 billion
  parameter model behaves on your hardware. Every action is validated, and Undo exists for a reason.
- FPS on real graphics cards, as before: VANTA promises no number.
